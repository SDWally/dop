# Python设计模式

##  

- 设计模式有助于我们借鉴其他人成功的经验
- 这个世界正在快速变化
- 尽管每个人都会写字，但世上仍旧会出现海明威似的人物

- 花时间掌握工具的人都能够抓住发展的机遇
- 工作质量，开发速度
- 积极主动地寻找和掌握不同地工具与技术，研究不同的框架和语言，弄明白其伟大的原因

- 可以反复使用的抽象方案
- 每一天都是让自己变得比前一天更优秀的新机会，每一行代码都是提升改进的机会

## 成为更优秀的程序员

- 当必须处理一段已有代码时，在处理完成之后应该让它比之前变得更好
- 尝试每天完成一个快速解决问题的挑战
- 寻求与编程技术比自己好的程序员共事的机会（开源项目是最好的机会）
- 专注于刻意训练
- 无论何时可以找到理由，都要练习系统化思考
- 收集和分析思维模型
- 熟练掌握工具并且理解它们适用于何处以及不适用于何处
